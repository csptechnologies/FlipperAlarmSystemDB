# GENERIC-4  (serial 0937768)

Generic, all 4 loops

Loops:
- L1 generic: Loop 1 (0x80)
- L2 generic: Loop 2 (0x20)
- L3 generic: Loop 3 (0x10)
- L4 generic: Loop 4 (0x40)

Files (event byte):
- 0937768 restore.sub = 0x00
- 0937768 L1_generic.sub = 0x80
- 0937768 L2_generic.sub = 0x20
- 0937768 L3_generic.sub = 0x10
- 0937768 L4_generic.sub = 0x40
- 0937768 L1_generic_L2_generic_L3_generic_L4_generic.sub = 0xF0
