# 5816MN  (serial 0482126)

Mini Door/Window Transmitter

Loops:
- L1 contact: Wired terminals (0x80)
- L2 reed: Reed switch (0x20)
- L3 contact: Wired terminals (alt) (0x10)
- L4 tamper: Case tamper (0x40)

Files (event byte):
- 0482126 close.sub = 0x00
- 0482126 L1_contact.sub = 0x80
- 0482126 L2_reed.sub = 0x20
- 0482126 L3_contact.sub = 0x10
- 0482126 L1_contact_L2_reed_L3_contact.sub = 0xB0
- 0482126 L4_tamper.sub = 0x40
