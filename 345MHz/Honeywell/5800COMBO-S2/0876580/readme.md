# 5800COMBO-S2  (serial 0876580)

Smoke/Heat/CO Combo (serial 2)

Loops:
- L1 co: CO alarm (0x80)
- L2 eol: CO end of life (0x20)

Files (event byte):
- 0876580 restore.sub = 0x00
- 0876580 L1_co.sub = 0x80
- 0876580 L2_eol.sub = 0x20
- 0876580 L1_co_L2_eol.sub = 0xA0
