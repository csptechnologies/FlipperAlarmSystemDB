# 5801  (serial 0634342)

4-Button Wireless Remote

Loops:
- L1 button: Button (loop 1) (0x80)
- L2 button: Button (loop 2) (0x20)
- L3 button: Button (loop 3) (0x10)
- L4 button: Button (loop 4) (0x40)

Files (event byte):
- 0634342 restore.sub = 0x00
- 0634342 L1_button.sub = 0x80
- 0634342 L2_button.sub = 0x20
- 0634342 L3_button.sub = 0x10
- 0634342 L4_button.sub = 0x40
- 0634342 L1_button_L2_button_L3_button_L4_button.sub = 0xF0
