# DSC PowerG
DSC PowerG is a Encrypted protocol. You will not be able to replay or use these files with your system. PowerG also hops frequencies so files in here may not be as accurate.

## PG9939
![PowerG fob](pg9939.jpeg)

The DSC PG9939 Keyfob is a 2 way encrypted keyfob. The keyfob does not hop frequencies unlike other PowerG Devices, but will send data that cannot be replayed due to rolling code style encryption. The panel will respond back to the keyfob each time with a secret key which will be used to calculate the next transmission/change the key.
